Installation (Kurzfassung)

  1. Steam-Bibliothek öffnen → The Rift Breaker → Rechtsklick → Verwalten → Lokale Dateien anzeigen (z. B. D:\SteamLibrary\steamapps\common\Riftbreaker).
  2. ZIP entpacken und den Inhalt (Ordner lua/) nach <Spielordner>\mods\riftbreaker_battle_mod\ kopieren (Ordner ggf. neu anlegen).
  3. Spiel starten und eine Karte laden — der Mod läuft automatisch (Log: <Dokumente>\The Riftbreaker\exor_logs.txt, Präfix [RBBATTLE]).

Ausführliche Anleitung inkl. In-Game-Konsole: README im Repo (mod/README.md).

Hinweis

Dieses Projekt enthält einen privaten Trainer-Anteil (Prozess-I/O am Spiel). Der Trainer wird nicht veröffentlicht — Downloads hier enthalten ausschließlich den Lua-Mod. Steam-Workshop-Upload ist nur für den Mod vorgesehen (docs/workshop.md).
