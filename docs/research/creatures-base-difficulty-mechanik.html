Was creatureDifficultyIncrementPerDOMDifficulty wirklich tut

Der seit #213 mitgeschleppte Caveat ist geklärt: kein Multiplikator auf die Survival-Units, sondern ein globaler Zähler für einen einzigen DLC2-Kampagnenboss, der im Survival-Modus nie vorkommt.

01 Der Signalweg

DOM-Level eskaliert (1→9) → dom_manager.lua:IncreaseCreaturesBaseDifficulty()
↓
Index = Spieleranzahl (1–4) → creatureDifficultyIncrementPerDOMDifficulty[index][level]
↓
Delta addiert auf globalen Float → CampaignService:IncreaseCreaturesBaseDifficulty(delta)
↓
Einziger Leser: anoryxian_boss_base.lua:SetupDifficulty()
↓
floor+clamp(1,10) → healthSetup[tier][spieler] → absolute HP gesetzt

02 Code-Belege

Der Schreiber (dom_manager.lua)

function dom_mananger:IncreaseCreaturesBaseDifficulty() local playersCounter = self:GetPlayersCounter() -- #PlayerService:GetConnectedPlayers(), max 4 local index = Clamp( playersCounter, 1, #self.rules.creatureDifficultyIncrementPerDOMDifficulty ) CampaignService:IncreaseCreaturesBaseDifficulty( self.rules.creatureDifficultyIncrementPerDOMDifficulty[index][self.currentDifficultyLevel] ) end
Rätsel gelöst: die vier Teiltabellen [1]–[4] aus #213/#736/Hard/Brutal sind exakt nach Spieleranzahl indiziert.

Der (einzige) Leser (anoryxian_boss_base.lua)

function anoryxian_base:SetupDifficulty() local creaturesDifficulty = CampaignService:GetCreaturesBaseDifficulty() local diff = math.max( 1, math.min( math.floor( creaturesDifficulty ), 10 ) ) local players = math.max( 1, math.min( playersCount, 4 ) ) local newHealth = self.healthSetup[diff][players] -- absolute HP, kein Multiplikator HealthService:SetMaxHealth( self.entity, newHealth ) end

Corpus-weiter Grep über alle lua/units/-Dateien: nur dieser Boss (+ 2 Subklassen) liest GetCreaturesBaseDifficulty. Keine der 6 Survival-Units (canoptrix, kafferroceros, arachnoid_sentinel, gnerot, bomogan, baxmoth) referenziert es.

04 Warum das für Survival egal ist

Der Boss-Trigger im Survival-Modus (attack_boss_dynamic.logic) spawnt zufällige Species-Blueprints (boss_jungle_random, boss_caverns_random, …) aus .kvp-Species-Pools.

PrüfungErgebnis
anoryxian in irgendeiner creature_species*.kvp0 Treffer
anoryxian in allen 1184 Dateien unter logic/missions/survival/0 Treffer
Endgültig bestätigt: Anoryxian ist eine rein skriptete DLC2-Höhlen-Kampagnenbegegnung (entryLogic = "logic/missions/campaigns/dlc_2/caverns_boss_intro.logic") und im Survival-Modus — egal ob Default, Hard oder Brutal — strukturell unerreichbar.

05 Was das für #736/Hard/Brutal bedeutet

01

Alle HP-Zahlen in #736, Hard- und Brutal-Dokument bleiben unverändert gültig — kein zusätzlicher Laufzeit-Multiplikator wirkt auf die 6 Survival-Units.

02

Der Caveat aus #213 §3 ("Kreaturen-Stärke skaliert zusätzlich, braucht Live-Test") ist geschlossen.

03

Die verglichenen Rohwert-Tabellen (Default/Hard/Brutal, Sub-Tabelle [1]) bleiben als Beleg korrekt, sind aber für die #205-Preisformel irrelevant.

06 Verbleibend offen

  • Ob Elite-Spawner/-Türme (creature_species_elite*.kvp) über einen anderen Pfad mit skriptgebundenen Bossen interagieren — außerhalb des Scopes, nicht relevant für #205.
  • Exakter Startwert von CreaturesBaseDifficulty (0 oder 1) nicht isoliert verifiziert — durch das math.max(1,...)-Clamp praktisch irrelevant.
