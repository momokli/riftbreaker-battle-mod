01 Der Pool wird noch radikaler ersetzt

Bei Hard kommt Alpha zusätzlich zu Plain in den Pool. Bei Brutal ist Plain komplett auskommentiert — nur noch Alpha + Ultra.

-- dom_survival_jungle_rules_brutal.lua, Level 1: { --"logic/.../attack_level_1_id_1.logic", -- Plain: ENTFERNT { name="attack_level_1_id_1_alpha.logic", ... }, { name="attack_level_1_id_1_ultra.logic", ... }, --"logic/.../attack_level_1_id_2.logic", -- Plain: ENTFERNT { name="attack_level_1_id_2_alpha.logic", ... }, { name="attack_level_1_id_2_ultra.logic", ... }, }
Kurioser Rohdaten-Fund: nicht jede _ultra-Datei enthält tatsächlich nur Ultra-Blueprints — z. B. attack_level_4_id_1_ultra.logic spawnt intern ausschließlich _alpha-Einheiten. Der Dateiname beschreibt die Wellen-Variante, nicht garantiert die Unit-Tier.
