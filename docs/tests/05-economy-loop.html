05 — economy-loop

test guide · tests 0/0 · validated 0/0

ZWECK

Geschlossener Economy-Kreis: Punkte verdienen (Kills eigener Kampfwellen via EntityKilledEvent; Fallback: HourEvent-Zeittick), ausgeben (rb_buy_wave <1..3>, Kosten 10/25/50, Spawn gegen die eigene Basis — Spawn-Logik aus Baustein 01, in-game verifiziert) und anzeigen (rb_points/rb_status). Eigenes Punkte-Konto des Mods (kein Spiel-Ressourcen-Zugriff — Recherche: docs/research/api-deep-dive.md), gespiegelt in Global-Database rbbattle_05_economy (PlayerService:GetOrCreateGlobalDatabase).

▸ INSTALL
  1. Ordner rbbattle_05_economy/ nach <SteamLibrary>\steamapps\common\Riftbreaker\mods\ kopieren (mods\ ggf. anlegen).
  2. Ergebnis: mods\rbbattle_05_economy\lua\rbbattle_05_economy_autoexec.lua.
  3. Spiel starten, Survival-Karte laden — Mod, Commands und Event-Handler laden automatisch.

TESTS

Log-Muster je Kauf:

[RBBATTLE] event=buy_wave level=1 cost=10 points=0 status=payed
[RBBATTLE] event=spawn ok blueprint=units/ground/brabit entity=<id>
[RBBATTLE] event=buy_wave level=1 cost=10 spawned=5 skipped=0 points=0 status=done
[RBBATTLE] event=points mode=kill status=kill_event_verified        -- nur 1. Kill
[RBBATTLE] event=points_add source=kill blueprint=units/ground/brabit pts=1 points=1

Kein In-Game-Lauf durch den Agenten möglich (Lua-Syntax nur per Parser geprüft) — alle Checkboxen sind Erst-Test-Erwartungen.
