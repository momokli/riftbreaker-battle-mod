ZWECK

Validiert den offiziellen Mod-Load-Pfad: Ordner-Layout mods/<ModName>/lua/*_autoexec.lua wird bei Kartenerstellung ausgeführt, LogService:Log schreibt ins Spiel-Log. Erwartet wird genau eine Zeile [RBBATTLE] skeleton ok pro Kartenerstellung — kein Command, kein UI.

▸ INSTALL
  1. Ordner rbbattle_00_skeleton/ nach <SteamLibrary>\steamapps\common\Riftbreaker\mods\ kopieren (Steam-Bibliothek z. B. D:\SteamLibrary; mods\ ggf. anlegen).
  2. Ergebnis: mods\rbbattle_00_skeleton\lua\rbbattle_00_skeleton_autoexec.lua.
  3. Spiel starten, beliebige Karte laden (Kampagne/Survival) — die Autoexec läuft automatisch, kein Aktivierungsschritt.

TESTS

Fehlt die Zeile → Mod-Ordner liegt falsch (Pfad prüfen) oder Engine-Layout mods/<ModName>/lua/*_autoexec.lua stimmt nicht.
