06 — tournament-server

test guide · tests 0/0 · validated 0/0

ZWECK

Server-Seite der Turnier-Architektur (docs/concept.md): N Spielinstanzen koppeln über einen Relay-Client an einen zentralen Tournament-Server — Spieler-Registrierung, Match-Anlage, Event-Zustellung per Polling/Outbox (Pull-Modell), Event-Routing (wave_sent → incoming_wave in die Outbox des Gegners), Runden-Lifecycle (Timer → round_end, Settle-Fenster → match_end mit Sieger), Scoreboard (score_update kumuliert). Reine Node-Standardbibliothek (node:http), keine npm-Dependencies, keine Persistenz/Auth. Event-Vertrag: trainer/protocol.md (Mapping im Baustein-README). Läuft auf Linux/Mac/Windows ohne Riftbreaker — vollständig testbar.

INSTALL

  1. Voraussetzung: Node.js (node --version; keine npm-Installation, keine Dependencies).
  2. rbb-06-tournament-server.zip entpacken → server.js, mock_client.js, test_e2e.sh, README.md.
  3. Server starten: node server.js — Port via env PORT (Default 8080); Log-Zeile „[server] tournament-server listening on port 8080 (settle_ms=3000)“.
  4. Selbsttest: bash test_e2e.sh → Exit 0 (Server + 2 Mock-Clients, 2 Runden à 4 s).
