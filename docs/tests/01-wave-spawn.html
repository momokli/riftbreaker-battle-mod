01 — wave-spawn

test guide · tests 0/0 · validated 0/0

ZWECK

Laufzeit-Spawning über die offizielle Service-API EntityService:SpawnEntity(blueprint, x, y, z, team) — exakt der Weg von EXORs Cheat-Command debug_spawn_entity (Team ""). Registriert genau einen Konsolen-Command rb_wave <level> mit 3 vordefinierten Wellen; kein UI, keine Bindings.

INSTALL

  1. Ordner rbbattle_01_wavespawn/ nach <SteamLibrary>\steamapps\common\Riftbreaker\mods\ kopieren (mods\ ggf. anlegen).
  2. Ergebnis: mods\rbbattle_01_wavespawn\lua\rbbattle_01_wavespawn_autoexec.lua.
  3. Spiel starten, Karte laden — die Command-Registrierung (rb_wave) erfolgt automatisch bei Kartenerstellung.

TESTS

Fehlerbilder: unbekannte Blueprints würden als reason=not_found übersprungen (kein Crash — Namen sind gegen Original-Spieldaten verifiziert); kein Spieler-Mech → event=wave ... status=no_player (graceful no-op).
