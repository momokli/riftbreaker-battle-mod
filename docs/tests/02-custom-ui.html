02 — custom-ui

test guide · tests 0/0 · validated 0/0

ZWECK

Custom-UI zur Laufzeit über die offizielle Service-API GuiService:OpenPopup(entity, "gui/popup/popup_template_1button", text) + globales GuiPopupResultEvent. Registriert genau einen Konsolen-Command (rb_ui), der ein Popup mit OK-Button am Spieler-Mech öffnet; Schließen nur per Button (kein API-Close dokumentiert). Kein Wave-Spawn, keine Bindings.

▸ INSTALL
  1. Ordner rbbattle_02_customui/ nach <SteamLibrary>\steamapps\common\Riftbreaker\mods\ kopieren (mods\ ggf. anlegen).
  2. Ergebnis: mods\rbbattle_02_customui\lua\rbbattle_02_customui_autoexec.lua.
  3. Spiel starten, Karte laden — Mod und Command (rb_ui) laden automatisch.

TESTS

In-Game-Test 08.09.2026 (Momo): komplett sauber — alle Tests bestanden ✓. Ohne Spieler-Mech (Karte nicht geladen) → event=ui_popup status=no_player (graceful no-op).
